# 🚀 HTML Quick Reference Guide 🌐

## 1. 📄 Content Tags
- **Basic Tags:** Structure of HTML like `<html>`, `<head>`, `<body>`, `<title>`.
- **Formatting Tags:** Style content like `<b>`, `<i>`, `<u>`, `<strong>`, `<em>`.
- **Computer Code Tags:** Display code or preformatted text like `<code>`, `<pre>`, `<samp>`.

## 2. 📋 Lists
- **Ordered List (`<ol>`):** Numbered list of items.  
- **Unordered List (`<ul>`):** Bulleted list of items.  
- **List Item (`<li>`):** Individual item inside a list.  
- **Definition List (`<dl>`):** List of terms and definitions, used with `<dt>` (term) and `<dd>` (definition).

## 3. 💬 Comments
- `<!-- comment -->` : Notes in code ignored by browser.

## 4. 🖼️ Favicon
- `<link rel="icon" href="favicon.ico">` : Browser tab icon.

## 5. 🔗 Links
- **Absolute Link:** Full URL like `https://example.com`.  
- **Relative Link:** Path relative to current page.  
- **Hyperlink:** Clickable text link.  
- **Button Link:** Button acts as a link.  
- **Email Link:** Opens email client.  
- **Image Link:** Image clickable as a link.

## 6. 📊 Table
- `<table>`, `<tr>`, `<th>`, `<td>` : Create table structure.  
- **Rowspan:** Merge cells vertically.  
- **Colspan:** Merge cells horizontally.

## 7. 📝 Forms
- **Input:** Get user input (text, number, color, date, file, etc.)  
- **Textarea:** Multi-line text input.  
- **Select & Option:** Dropdown list.  
- **Button:** Clickable button for actions.
